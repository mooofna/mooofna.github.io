Three general skills for Claude, each backed by tested Python scripts: paper-to-obsidian files handwritten pages into an Obsidian vault with a document scanner, anki-lecture-cards turns lecture material into Anki decks, and curriculum-solver enumerates every valid study plan instead of guessing one. Installable in Claude Code as a plugin marketplace.
